# 测试覆盖地图

## 现有覆盖

仓库当前没有自动化测试文件、测试框架或 `npm test`，也没有 GitHub Actions。

| 检查 | 能证明什么 | 不能证明什么 | 状态 |
| --- | --- | --- | --- |
| `npm run typecheck` | TypeScript 类型可以通过 | 页面行为、权限和数据库一致性 | 已有脚本 |
| `npm run build` | 类型检查和 Vite 生产构建成功 | 登录、写入、RLS 和真实部署行为 | 已有脚本 |
| 本机浏览器验收 | 当前改动的主要页面交互 | 无法持续防止回归 | 人工执行 |
| Vercel 上线冒烟 | 正式站能加载及核心交互可用 | 深层权限和并发问题 | 人工执行 |

没有任何测试会自动阻止问题代码合并到 `main`。

| --- | --- | --- | --- | --- |

| P0 | 拼桌并发 | 同时加入不超员，重复加入不重复计数，退出后人数一致 | 自动化集成 | 待实现 |

| P1 | 搜索 | `印尼 鸡`、`鸡 印尼`、`印尼鸡`、大小写和无结果 | 自动化单元 | 待实现 |
| P1 | 评价 | 匿名发布失败，登录用户只能提交自己的身份 | 自动化集成 | 待实现 |

## 主要空白

1. 无法从仓库验证线上 RLS 与 RPC 权限是否已正确部署；
2. 没有覆盖拼桌人数一致性和并发加入；
3. 没有覆盖账号枚举风险与密码恢复流程；
4. 没有覆盖不同账号共用浏览器时的本地优惠券；
5. 没有 CI，构建与测试不是合并门禁。
